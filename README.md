# Scholz Kitchen

A personal kitchen, meal-planning, and grocery web app for one household. Installs to an iPhone home screen, works offline in the store, costs $0/month: static files on GitHub Pages, data in a private Google Sheet behind an Apps Script API.

This repo holds code only. All household data lives in the owner's private Sheet.
